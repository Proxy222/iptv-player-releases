# IPTV Player — download

A TiviMate-style IPTV player for Windows: live TV with a TV guide, movies and shows, saved playlists, and clear error messages.

## Install

1. **[Download IptvPlayerApp-win-Setup.exe](https://github.com/Proxy222/iptv-player-releases/releases/latest/download/IptvPlayerApp-win-Setup.exe)**
2. Run it. The app installs in a few seconds and opens. No admin rights needed.
   - If Windows says **"Windows protected your PC"**, click **More info → Run anyway**. It shows because the app isn't code-signed.
3. Add your playlist on the **Playlists** page: your Xtream Codes login or M3U link from your IPTV provider.
   Want to try it first? Add the free M3U URL `https://iptv-org.github.io/iptv/index.m3u`.

**Needs:** Windows 10 or 11, 64-bit.

## Updates

The app updates itself. When a new version is out you'll see **Update available** in the top-right corner when it starts. Click **Update** and it restarts on the new version. Your playlists and favourites are kept.

## Uninstall

Windows **Settings → Apps → Installed apps → IPTV Player → Uninstall**.
